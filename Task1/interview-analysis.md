# Анализ предоставленных интервью

Источник — учебные стенограммы B/S/D1/D2/D3, а не ответы на проведённые автором встречи. Вопросы в таблице — ориентиры исходной беседы (сокращённый пересказ). ## Межисточниковые расхождения

1. B ждёт устойчивого клиентского обещания; S/D2 описывают изменение доставки после оформления. Это разрыв потребности и текущего поведения, не основание придумать допустимую задержку.
2. D1 называет формальный набор статусов, S не может объяснить их клиенту, D3 по-разному считает их в отчётах. Нужны отдельные представления с общей семантической привязкой, а не просто новый enum.
3. D1 описывает fallback промо при недоступности; C:78–85 показывает fallback при пустом Optional, без видимого catch. Эти условия не тождественны. Нужны контракт и реальные трассы; пока не утверждаем одинаковое поведение.
4. D1 сообщает о длинных транзакциях; C не содержит настройки транзакций. Связь рисков с внешними вызовами обоснована как риск, конкретное время удержания блокировок не доказано.

Следующие действия: Q-01/09 со спонсором; Q-03/04 с заказами/поддержкой; Q-07/08/12 с DBA и техлидом. Отсутствующие ответы не заменяются вымышленной стенограммой.
